ara::ucm - conformance to AUTOSAR AP R25-11 (SWS Update and Configuration Management)

Audited against AUTOSAR_AP_SWS_UpdateAndConfigurationManagement.pdf (R25-11) and, for requirement text that the R25-11 extract did not contain, the R22-11 edition.

Verification limits. The readable part of each PDF stops before chapter 9, so the formal interface block (argument names/types, return types), the enum literal values and the numeric UCMErrorDomain values were not available - they are Unverified. Method names, the per-method error lists, the check order and the requirement ids are copied from the readable text. R22-11 ids are marked (R22).

Status legend as in sm.md.

PackageManagement methods

R25-11 lists: Activate, Cancel, DeleteTransfer, Finish, GetHistory, GetId, GetProgress, GetSwClusterChangeInfo, GetSwClusterInfo, GetSwClusterManifestInfo, GetSwPackages, ProcessSwPackage, RegisterSoftwarePackage, RevertProcessedSwPackages, Rollback, TransferData, TransferExit, TransferStart.

Out of scope

  • UCM Master / Vehicle UCM - split into a separate specification in R23-11 (SWS_VehicleUpdateAndConfigurationManagement); the R25-11 UCM text contains no master API.

What changed in this audit

  • ucm_core.h (new, header-only): the CurrentStatus state machine and the transfer bookkeeping with the SWS guards and error codes; thread-safe; 33 tests in Testing/ucm. The skeleton delegates to it.
  • Bugs fixed on the way:
  • the last block was silently dropped when the package size is a multiple of the block size;
  • TransferData never returned an error (and TransferDataOutput was uninitialised);
  • TransferExit, ProcessSwPackage and Finish built the package file name three different ways, so Finish never found the file - all now use the 32-hex transfer id; transfers no longer share one global buffer, so parallel transfers do not corrupt each other;
  • CurrentStatus never changed;
  • ActionType, ResultType, SoftwarePackageStepType, CampaignFailureType, CampaignStateType, TransferStateType were aliases to uint8_t &, which made the structs that use them unusable;
  • missing/garbled sw.conf, a missing binary or one shorter than the 52-byte header could crash ProcessSwPackage; they now return InvalidPackageManifest / ProcessedSoftwarePackageInconsistent.

Suggested next steps

  1. Add an error channel to the service outputs (or switch to ara::core::Result with the R25-11 names).
  2. Connect Activate / Rollback to State Management's UpdateRequest (PrepareUpdate, VerifyUpdate, ResetMachine) - the UpdateSession rules now exist on the SM side.
  3. Package validation (format, authentication, manifest, version) and persistence of the UCM state.
  4. Obtain the complete PDF to confirm chapter 9 (signatures, literal and error values).

Gap closure (feature/gap-com-sm-ucm)

Source policy: requirement IDs below were checked against the R25-11 text where it was readable and against R22-11 / R24-11 otherwise (the change between releases is small for PackageManagement). The later chapters (enum values, error numerics, exact signatures) are unreadable in all three PDFs, so those stay Unverified.

Item Status Notes (tests: Testing/ucm/ucm_core_hooks_test.cpp, 28 tests)
Activate talks to State Management Implemented UpdateHooks::prepareUpdate then resetMachine; failure -> UpdateSessionRejected / PreActivationFailed (00258, 00242). R22-11 text
Verify / kVerifying Implemented kActivated -> kVerifying -> hook; failure -> VerificationFailed, stays kVerifying (00280)
Rollback with PrepareRollback + ResetMachine Implemented NotAbleToRollback on hook failure, state restored (00110)
Revert with hook Implemented NotAbleToRevertPackages (00236)
kProcessingFailed Implemented failed processing -> kProcessingFailed (00392); BeginProcess may retry from it. Numeric value Unverified
Package validation at TransferExit Implemented consistency / authentication / version hook (00294, 00098, 00092, 00103); the package stays kTransferring so the client can delete or retry. Design decision, not spec-mandated
GetHistory / GetId Implemented operation log (sequence, time, action, transfer id, result). Cluster names are not tracked
Persisting UCM state Implemented Save/Load (00184, 00273)

Still missing: GetSwClusterChangeInfo, GetSwClusterManifestInfo, RegisterSoftwarePackage, kCancelling campaign handling (00297/00298), delta/stream processing details.
