Detailed Description

Wire format of execution errors from Execution Management to State Management (SWS_EM_01309 / SWS_EM_02543) plus the abnormal-termination decision, shared by the EM application and ara::exec::StateClient so both sides agree and can be unit tested.

One newline-terminated line per event: "<function group>/<execution error>\n".
