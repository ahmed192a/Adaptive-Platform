Detailed Description

ara::core::Result<T, E> and Result<void, E> (SWS_CORE_00701 ff.)

A Result either contains a value of type T or an error of type E (default ara::core::ErrorCode). It is the exception-free error transport of all Adaptive Platform APIs.
