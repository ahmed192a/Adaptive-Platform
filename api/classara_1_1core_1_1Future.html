◆ then()

template<typename T , typename E >
template<typename F >
auto ara::core::Future< T, E >::then ( F &&  func)
inline

Attach a continuation.

func receives this Future (ready) and returns a plain value U or a Result<U,E>; then() returns a Future<U,E>. The continuation runs on the thread that fulfils the Promise (or immediately on the calling thread if already ready).
