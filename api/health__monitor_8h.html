Detailed Description

PHM engine: owns the supervisions, aggregates global supervision status and dispatches recovery.

In a deployed system this runs inside the PHM daemon; here it is a library object so that it can be hosted in-process (see HealthMonitor::Instance()) or behind an IPC transport implementing CheckpointSink.

Time is always passed in, so behaviour is fully deterministic in tests.
