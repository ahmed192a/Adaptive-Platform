Detailed Description

Measurement record for the time precision measurement table (SWS_TS_00800 / 00801 lists the fields; their exact types are Unverified).

For offset time bases only glbSeconds, glbNanoSeconds and timeBaseStatus are filled (SWS_TS_00801), the other fields are 0.
