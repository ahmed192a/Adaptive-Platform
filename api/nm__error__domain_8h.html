Detailed Description

ara::nm::NmErrc / NmErrorDomain / NmException (SWS_ANM_01100 ff.)

kServiceNotAvailable = 1 and kInvalidHandler = 2 are the normative codes (SWS_ANM_01111). Codes >= 0x100 are implementation extensions used by the NmChannel engine. The numeric domain id is not given in the retrievable SWS text (it defers to SWS_CORE_90023) and is an implementation choice - see doc/spec-conformance/nm.md.
