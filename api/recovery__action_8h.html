Detailed Description

ara::phm::RecoveryAction (SWS_PHM) - State Management's recovery callback.

In R24-11 the class is final; the handler is supplied at construction. While offered, PHM invokes the handler when a global supervision that references this action expires. Returning (a Future holding) an error - typically PhmErrc::kSMCanNotHandleRecovery - makes PHM fire the watchdog.
