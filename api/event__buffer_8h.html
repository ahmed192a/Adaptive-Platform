Detailed Description

Spec-shaped proxy-side event sample queue (SWS_CommunicationManagement ProxyEvent API): Subscribe(maxSampleCount), Unsubscribe, GetSubscriptionState, SetSubscriptionStateChangeHandler, GetNewSamples, GetFreeSampleCount, SetReceiveHandler / UnsetReceiveHandler.

Transport independent: the binding calls Push() for each received event and OnSubscriptionAck() when the service acknowledged (or refused) the subscription. API names are those of the SWS index (R24-11); the exact signatures and the overflow policy were not readable and are Unverified. Decisions: a full queue drops its OLDEST sample; GetNewSamples on a non-subscribed buffer yields 0 samples.
