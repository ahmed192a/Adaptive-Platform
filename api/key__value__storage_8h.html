Detailed Description

ara::per::KeyValueStorage (SWS_PER, chapter "Key-Value Storage")

Semantics implemented:

  • Reads/writes operate on an in-memory image; SyncToStorage() persists it atomically (temp file + fsync + rename) together with a CRC-32. The previous version is kept as redundancy ("<file>.bak").
  • DiscardPendingChanges() rolls back to the last synced state.
  • All methods are thread safe.
  • Destroying the handle does NOT implicitly sync; call SyncToStorage().
