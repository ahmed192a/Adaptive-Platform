Result< void > ara::nm::NetworkManager::InstallSigtermHook ( )
static

Install a SIGTERM handler that only sets a flag (async-signal-safe).

The next ProcessAll() or ServiceSignals() then runs ShutdownAll(). A previously installed handler is chained. Idempotent; kInvalidConfig if sigaction fails.
