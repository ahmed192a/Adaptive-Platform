Detailed Description

ara::core::Initialize() / Deinitialize() (SWS_CORE_10001, SWS_CORE_10002)

Initialize() brings up the AUTOSAR Adaptive runtime of the process, i.e. every functional cluster that registered a lifecycle hook. Clusters register themselves through ARA_REGISTER_LIFECYCLE_HOOK().
