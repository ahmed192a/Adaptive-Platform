Detailed Description

apext::phm::WatchdogInterface (SWS PHM, Appendix C)

Abstraction of the platform specific hardware/software watchdog. PHM calls AliveNotification() each evaluation while the platform is healthy and FireWatchdogReaction() when a supervision failure cannot be recovered.
