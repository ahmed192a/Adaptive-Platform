Detailed Description

Transport-independent update-session rules of the State Management UpdateRequest service interface.

  • only one update session may be active at a time ([SWS_SM_00209],[SWS_SM_00210])
  • PrepareUpdate / VerifyUpdate / PrepareRollback / StopUpdateSession are rejected with kOperationRejected outside an active session ([SWS_SM_00213])
  • the session status survives a machine reset ([SWS_SM_00204])

Whether ResetMachine itself requires an active session is not stated in the parts of the R25-11 text that could be read; it is implemented as "requires an active session" (see doc/spec-conformance/sm.md).
