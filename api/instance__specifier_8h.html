Detailed Description

ara::core::InstanceSpecifier (SWS_CORE_08001 ff.)

Identifies a PortPrototype by the shortname path in the application manifest, e.g. "MyApp/RPort_Persistency". Valid values are non-empty paths of shortnames ([A-Za-z][A-Za-z0-9_]*) separated by single '/' characters, without leading or trailing '/'.
