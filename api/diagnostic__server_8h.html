Detailed Description

Transport-independent UDS request dispatcher.

The server turns a request PDU into a response PDU. It implements the session layer (0x10, 0x3E, S3 timeout), 0x22/0x2E on registered data identifiers and 0x11, and lets applications add services. Transport (DoIP / ISO-TP) is out of scope and is expected to call Dispatch().

This is the engine below the SWS ara::diag service interfaces; the AUTOSAR-shaped facade (Conversation, GenericUDSService, GenericRoutine, GenericDataIdentifier, Monitor) lives in diag_facade.h on top of it.
