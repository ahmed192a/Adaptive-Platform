Detailed Description

SWS-facing Time Synchronization API (AUTOSAR AP R25-11): SynchronizedTimeBaseConsumer, SynchronizedTimeBaseProvider, SynchronizedTimeBaseStatus.

The classes are bound to a time base by their InstanceSpecifier through TimeBaseRegistry (TimeBaseRegistry::Bind). An unbound consumer/provider behaves like one whose time-sync daemon connection was lost. Signatures that the retrievable SWS text does not give (callback types, Register* return types, user-data type) are marked "unverified" in doc/spec-conformance/tsync.md. ara::core::Span is not used (it does not compile under -Werror), user data is passed as pointer + length / returned as vector.
