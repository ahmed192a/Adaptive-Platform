Detailed Description

Synchronized time base: consumer view (TimeBaseResource) and provider (TimeBaseProvider).

A time base is a continuously running synchronized time derived from the local steady clock:

T(now) = T_sync + (now - local_at_sync) * (1 + rateDeviation) + slewed offset correction

The local clock is injectable so behaviour is deterministic in tests. Provider updates that differ from the current time base by less than stepThreshold are slewed in over slewWindow, larger ones step the time (and raise a notification). If no update arrives within timeout the TIMEOUT flag is raised and SYNCHRONIZED cleared until the next update.
