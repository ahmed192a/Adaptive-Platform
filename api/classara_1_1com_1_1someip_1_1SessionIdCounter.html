Detailed Description

Session ID generator.

Active: 1, 2, ..., 0xFFFF, 1, ... (never 0) [PRS_SOMEIP_00933, 00521]. Inactive: always 0 [PRS_SOMEIP_00932]. For SD the Reboot flag is set until the counter wrapped for the first time [PRS_SOMEIPSD_00255].
