Detailed Description

Additional OpenSSL-backed primitives for ara::crypto: key derivation, AES-CBC/CTR, AES key wrap, RSA (PSS / OAEP), SecretSeed and X.509 certificates.

Like crypto.h this is the primitive layer; the SWS-shaped factories in provider.h wrap it. All fallible operations return ara::core::Result; nothing throws.
