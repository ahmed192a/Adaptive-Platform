Detailed Description

Configurable State Management model: StateMachine with RequestTransition, the StateManager that owns the machine-level state machines and the initial transition, the function-group RecoveryHandler registry and the NetworkHandle bridge.

Header-only and transport independent (no sockets, no Execution Management): the SM application plugs its own actions in (for example "ask Execution Management to set function group X to state Y"). Requirement ids are SWS_SM_xxxxx as named in doc/spec-conformance/sm.md; the numeric values of the error enumerators are Unverified (chapter 8 of the SWS could not be read).
