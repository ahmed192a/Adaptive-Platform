1// persist_logger_app: a tiny "vehicle data logger" that shows ara::log and ara::per working together.
2// * boot counter and settings live in a key-value storage (survive restarts)
3// * every run appends a trip record to a file storage, which keeps a CRC-protected redundancy copy
4// * --corrupt damages the trip file on purpose and RecoverAllFiles() restores it
5// Usage: persist_logger_app [--dir <path>] [--corrupt]
