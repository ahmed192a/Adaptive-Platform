Detailed Description

ara::core::FutureErrc / FutureErrorDomain / FutureException

The domain id 0x8000'0000'0000'0013 is stated in the R23-11 SWS_Core (SWS_CORE_00013). The numeric values of FutureErrc follow the std::future_errc values used by the SWS; they could not be re-verified against the R25-11 chapter 8 text (see doc/spec-conformance/core.md).
