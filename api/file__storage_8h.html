Detailed Description

ara::per::FileStorage, ReadAccessor, ReadWriteAccessor, OpenMode (SWS_PER)

Files live in <storage directory>/files/. A file can be open only once at a time (kResourceBusy). Quotas (maxSize over all files, maxFiles) are enforced when growing / creating files.
