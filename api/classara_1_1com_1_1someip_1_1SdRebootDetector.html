Detailed Description

Receiver-side reboot detection of a remote SD peer.

Unicast and multicast SD messages keep separate session counters [PRS_SOMEIPSD_00160, 00256]. A reboot is detected when the Reboot flag goes 0 -> 1, or stays 1 while the Session ID does not increase [PRS_SOMEIPSD_00258].
