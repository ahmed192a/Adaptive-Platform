Detailed Description

ara::nm::NetworkHandle - the State Management facing API of Network Management (SWS_ANM_01000 ff., AUTOSAR AP R25-11).

A handle is bound to a NetworkManagementPortInterface port by its InstanceSpecifier. In this implementation the binding is made with NetworkManager::BindPort(); an unbound handle reports kServiceNotAvailable like a handle whose NM daemon connection was lost.
