Detailed Description

Configurable NM PDU layout (nmPduLength, nmNidPosition, nmCbvPosition, pncVectorOffset / pncVectorLength, SWS_ANM_00033..00040, 00055).

Every byte that is not the node id, the control bit vector or the PN vector is user data. The default reproduces the fixed 8 byte layout.
