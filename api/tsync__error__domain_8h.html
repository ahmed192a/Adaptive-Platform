Detailed Description

ara::tsync::TsyncErrc / TsyncErrorDomain.

The SWS (R25-11) names kDaemonConnectionLost, kFunctionNotSupported and kLimitsExceeded; the retrievable SWS text gives neither their numeric values nor the domain id (it defers to SWS_CORE_90023), so values and id are implementation choices - see doc/spec-conformance/tsync.md. The domain id is distinct from ara::nm's (they used to collide).
