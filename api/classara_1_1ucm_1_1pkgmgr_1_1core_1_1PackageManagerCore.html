◆ Load()

bool ara::ucm::pkgmgr::core::PackageManagerCore::Load ( std::string const &  path)
inline

Restore a state written by Save().

States that were in flight when the machine went down are resolved conservatively: processing -> package kProcessingFailed and kReady/kIdle; activating (the reset itself) -> kActivated (the new software is running; verify next); rolling back -> kRolledBack; cleaning up -> kIdle. Returns false (state untouched) for a missing / malformed file.
