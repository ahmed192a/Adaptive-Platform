Detailed Description

SOME/IP session handling: Session ID counter, request/response matching and the receiver-side reboot detection of SOME/IP-SD.

Ids in the comments are PRS_SOMEIP_xxxxx / PRS_SOMEIPSD_xxxxx as listed in doc/spec-conformance/com.md. The code is transport independent.
