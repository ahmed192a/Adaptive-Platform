Detailed Description

AUTOSAR-shaped facade over DiagnosticServer: Conversation, GenericUDSService, GenericRoutine, GenericDataIdentifier and Monitor.

Class and method names follow the SWS Diagnostics table of contents (Offer / StopOffer / HandleMessage / Start / Stop / RequestResults / ReportMonitorAction). Signatures are pragmatic: they use ara::core::Result and plain byte vectors instead of the SWS Future / OperationOutput / MetaInfo types, and the numeric values of the enumerators are implementation choices (see doc/spec-conformance/diag.md).
