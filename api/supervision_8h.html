Detailed Description

Elementary supervisions (alive, deadline, logical) of PHM.

Pure state machines: they never read a clock themselves, every call gets the current time, which makes them deterministic and unit-testable.

Semantics (SWS Platform Health Management, chapter "Supervision"):

  • Alive: every reference cycle the number of indications must be within [expected - minMargin, expected + maxMargin]. A bad cycle raises the failure counter (status FAILED); a good one lowers it. Counter > failedReferenceCyclesTolerance => EXPIRED.
  • Deadline: time between start and end checkpoint must be within [minDeadline, maxDeadline]; otherwise EXPIRED.
  • Logical: checkpoints must follow the configured transition graph; a violation => EXPIRED. EXPIRED is final until the supervision is deactivated and activated again.
