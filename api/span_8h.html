Detailed Description

ara::core::Span (SWS_CORE_01901 family): a non-owning view of a contiguous sequence.

Complete implementation (the previous header only declared the interface and did not compile under -Werror because of the deprecated std::iterator). Iterators are plain pointers, which satisfy the RandomAccess/Contiguous iterator requirements. See doc/spec-conformance/core.md.
