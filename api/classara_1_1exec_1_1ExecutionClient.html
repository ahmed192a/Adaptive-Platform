◆ Create()

ara::core::Result< ExecutionClient > ara::exec::ExecutionClient::Create ( std::function< void()>  terminationHandler)
staticnoexcept

Spec-shaped factory (SWS_EM_02577): creates the one ExecutionClient of this process and installs a SIGTERM handler that runs terminationHandler on a background thread.

Returns
the client, or an error when a Create()d client already exists in this process (ExecErrc::kGeneralError, SWS_EM_02582) or the handler is empty (kInvalidArguments).
Note
The legacy default constructor stays available and unrestricted: several platform processes still hold more than one client. Only Create()d clients are subject to the single-instance rule. The exact signature of the spec's Create is Unverified (see doc/spec-conformance/exec.md).
