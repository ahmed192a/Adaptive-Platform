Detailed Description

ara::crypto - a compact cryptography provider on top of OpenSSL.

Offers: random generation, SHA-2 hashing, HMAC, AES-GCM AEAD, Ed25519 and ECDSA-P256 signatures, and a usage-restricted SecretKey / KeyStore.

This is NOT yet the SWS CryptoProvider/CryptoContext object model (CryptoProvider, KeySlot, X509 ...); it is the primitive layer that facade will use. All fallible operations return ara::core::Result; nothing throws.
