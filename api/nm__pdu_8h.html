Detailed Description

8 byte NM message (CAN-NM like layout).

byte 0 source node id byte 1 control bit vector: bit0 repeat-message-request, bit4 partial-network-info; other bits are reserved (written 0, ignored on receive) bytes 2..5 partial network request bitmap, little endian (valid iff PNI is set) bytes 6..7 user data
