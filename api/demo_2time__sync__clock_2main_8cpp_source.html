1// time_sync_clock - a time-base provider (the "master") and a consumer (an application) sharing one
2// synchronized time base. A simulated local clock makes the run instant and reproducible. Shows
3// slew correction (small offset), step correction (large offset, leap jump), rate correction and
4// the timeout when the provider falls silent.

35void Show(char const *what) {
