Detailed Description

Transport-independent UCM PackageManagement logic: the UCM state machine (CurrentStatus) and the transfer / processing bookkeeping.

The SOME/IP skeleton owns file I/O and the flashing hardware; this class owns every rule that the AUTOSAR UCM SWS puts on the order of calls and on the ApplicationErrors they raise, so that those rules can be unit-tested without sockets. All methods are thread-safe. Error values are UCMErrorDomain enumerators (0 means success).

Requirement ids in comments are SWS_UCM_xxxxx as printed in R22-11/R25-11 (see doc/spec-conformance/ucm.md for what is verified and what is not).
