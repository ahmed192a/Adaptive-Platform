Detailed Description

Demo application: a complete software update driven through the UCM PackageManagement rules (ara::ucm::pkgmgr::core::PackageManagerCore) with ara::sm State Management on the other side (UpdateSession + a configurable StateMachine).

Everything runs in-process (no SOME/IP sockets), so the whole flow is deterministic and testable: TransferStart -> TransferData (blocks) -> TransferExit (package digest check) -> ProcessSwPackage -> Activate (State Management PrepareUpdate / ResetMachine) -> Verify -> Finish, or Rollback on failure.
