Known deviations (new clusters)

  • Numeric values of PerErrc/PhmErrc/LogErrc and the error-domain ids are implementation choices and must be checked against the SWS tables.
  • PHM reports expiry through ExpiredSupervision (not ara::exec::ExecutionErrorEvent) until exec provides that type.
  • ara::core::Result has extra non-const Value()& / operator*()& overloads.
  • A Promise destroyed unfulfilled leaves its Future pending (no broken-promise error yet).
  • ara::log has no remote (DLT) sink; LogMode::kRemote is accepted and ignored.

Fixed legacy defects

  • EM/StateClient FIFO framing — requests were written without a delimiter, so two quick requests (FG_1/off then MachineFG/off) were read as one (FG_1/offMachineFG/off) and the platform hung. Requests are now newline terminated and Execution Management re-assembles them, ignores malformed ones and survives writers closing the FIFO.
  • Missing <cstdint> in the log headers (build break), exit() on a missing manifest, a dangling reference in StateClient::SetState, an empty ara::core::Result.

Findings in legacy code (not yet fixed)

  • EM: ERROR: coundn't Terminate the process … appears during shutdown for processes that already exited (process bookkeeping in Process::terminate()); harmless but noisy.

  • Warnings: OTA/client.cpp:120, SomeipSDMessage.cpp (range-for copies), socket_Server.cpp:135, packagemanagement_skeleton.cpp (unused variables), deserializer.h:84 (memcpy into a vector), exec_main.cpp:205, service_skeleton.h:148, deterministic_client.cpp:65 (ignored read result).

  • Legacy tests rely on the working directory (manifests are copied to the build dir).
  • Legacy targets use ap::legacy (-Wall) instead of the strict ap::warnings; migrate cluster by cluster.

Platform demo node

ap_dashboard (App/dashboard) hosts PHM, diag, per, crypto and log in one process, controls the legacy Execution Management and serves the web console. It is a demo/test harness, not part of the AUTOSAR scope: no authentication, loopback only. Open items: show the SOME/IP service discovery traffic, a DTC/fault-memory view once ara::diag has it, and Remote persistency.
